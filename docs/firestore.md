# Данные в Firestore

## `config/groups` — список групп

Документ `groups` в коллекции `config`. Приложение показывает группы в том же порядке, что и в массиве.

```json
{
  "groups": [
    { "id": "1_readers", "name": "Подгруппа 1 - Чтецы", "short": "Гр.1 Чтецы" },
    { "id": "1_singers", "name": "Подгруппа 1 - Певцы", "short": "Гр.1 Певцы" },
    { "id": "2_readers", "name": "Подгруппа 2 - Чтецы", "short": "Гр.2 Чтецы" },
    { "id": "2_singers", "name": "Подгруппа 2 - Певцы", "short": "Гр.2 Певцы" }
  ]
}
```

- `id` — имя документа с расписанием в коллекции `schedules`. Обязательное поле.
- `name` — полное название: экран выбора и диалог «Посмотреть другие». Обязательное поле.
- `short` — короткое название для тулбара и виджета. Если не указано, берётся `name`.

Записи без `id` или `name` пропускаются. Если документа нет или в нём нет ни одной корректной записи,
приложение показывает встроенный список из четырёх групп выше.

Чтобы добавить группу: создайте документ расписания в `schedules` и добавьте запись в `groups`.
Выпускать новую версию приложения не нужно.

`id` уже выбранной студентами группы менять нельзя — у них пропадёт расписание. Название менять можно.

## `schedules/<id>` — расписание группы

```json
{
  "schedule": {
    "monday": [
      { "id": 1, "startTime": "9:00", "endTime": "10:30", "subject": "Математика",
        "teacher": "Иванов И.И.", "room": "101",
        "cancelled": false, "cancelledDates": ["2026-10-27", "2026-11-03"] }
    ],
    "tuesday": []
  }
}
```

Дни: `monday` … `sunday`. Время — `ЧЧ:ММ`, ведущий ноль необязателен.
Отмены:
- `cancelledDates` — разовые отмены: список дат `ГГГГ-ММ-ДД`. В эти дни пара показывается зачёркнутой,
  о ней не приходит напоминание и её пропускает виджет; в остальные недели она обычная.
  Необязательное поле. В консоли Firebase это поле типа array со строками.
- `cancelled: true` — пара отменена на всех неделях.

Прошедшие даты из `cancelledDates` можно не удалять — они ни на что не влияют.

## Правила доступа

Приложению нужен доступ на чтение к `config/groups` и `schedules/*`. Запись из приложения не нужна:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /config/groups { allow read: if true; allow write: if false; }
    match /schedules/{groupId} { allow read: if true; allow write: if false; }
  }
}
```
